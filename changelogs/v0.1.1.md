# v0.1.1 — 2026-10-25

- Add optional edge `map` to project source input, source output, run inputs, or prior node results into the next node's input. Omitting it forwards the source output; `{}` sends an empty object.
- Show edge maps in graph descriptions and the web inspector.
- Allow unlimited graph cycles only when `allowUnboundedCycles: true` is explicitly set. Bounded cycles remain the default requirement.
- Run sibling nodes concurrently with `dispatch: "all"` and resume at a `join.from` barrier after every named predecessor has supplied its payload. Active nodes and partial join inputs are persisted across external waits and process restarts.
- Fix the missing `forkCommand` property in the executor registration schema.

See `examples/parallel.json` for a runnable parallel workflow. A join currently waits for all declared predecessors; first-winner cancellation is not supported.
