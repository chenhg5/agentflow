# v0.0.4 — 2026-10-24

- Workflow version 2 uses explicit entry, nodes, conditional edges, terminal edges, and bounded cycles. Removed formats are rejected.
- Nodes reference one executor; programs and built-in agent adapters share JSON input/output contracts.
- `.agentflow/executors.json` registers custom command entry points, workspace, and environment.
- External output submission uses `run submit --output JSON`; business field names and values are user defined.
- The web graph and metrics report executor references and per-visit execution history.
- CLI schemas are embedded; workflow input references and executor registrations can be checked before execution, and unknown trigger fields are rejected as nonretryable input errors.
- Empty object inputs survive persisted waits/revisits; run history is consistently an array.
- A cold-context authoring benchmark includes four goldens, deterministic mutation tests, arbitrary fresh-agent CLI runs, retained evidence, and a model-free CI gate.
