## v0.0.1 — 2026-10-10

First public preview of AgentFlow, a standalone Go CLI and local web UI for durable workflows that coordinate shell commands, Claude Code/Codex sessions, and human approvals.

**Status: preview.** Workflow schema, provider configuration, and CLI behavior may still change before 1.0.

### Highlights

- JSON workflow definitions with shell, agent, and human nodes, dependencies, conditions, retries, timeouts, and resumable runs.
- Explicit agent workspace and session binding, including provider `resumeCommand` support for existing Claude Code and Codex sessions.
- Structured node result files through `AGENTFLOW_RESULT_FILE`; stdout/stderr remain separate log artifacts.
- Durable run state, append-only events, human approve/reject, cancellation, idempotent starts, and local artifacts under `.agentflow/runs/`.
- CLI metrics and historical stats for duration, human waiting time, attempts, input/output sizes, and log sizes.
- Embedded local web visualization for workflow definitions and live run graphs using a React Flow based UI.
- Agent onboarding skill at `skills/agentflow/SKILL.md`.
- English installation and usage guide at `INSTALL.md`.

### Install

```bash
go install github.com/chenhg5/agentflow/cmd/agentflow@v0.0.1
```

Or download the platform archive from the GitHub release and run `agentflow version`.

### Known limitations

- The web UI currently loads React Flow dependencies from public CDNs, so the browser needs network access to load the graph UI.
- Drivers are command templates rather than native vendor SDK integrations; provider command syntax must match the installed CLI.
- A single run advances nodes in the runner process; independent runs can run concurrently, but sharing one external agent session concurrently may conflict.
