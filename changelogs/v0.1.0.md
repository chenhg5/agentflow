# v0.1.0 — 2026-10-24

This release adopts workflow JSON version 3. Version 2 workflows and the node-level `input` field are no longer accepted; migrate existing workflow files before upgrading.

- Pass run inputs to entry nodes and pass each source node's JSON result across edges. Keep node configuration separate from runtime input.
- Add agent session policies: `new`, `fixed`, `inherit`, and `fork`. Session identity is managed by the engine instead of being passed as business input.
- Support session creation, resumption, and forking for Codex, Claude, and custom executors with configured commands and session files.
- Show node configuration and session information in the web inspector, with language, theme, and layout controls.
- Add run evaluation and comparison commands, plus execution and measurement metrics.
- Update examples, documentation, the AgentFlow skill, and workflow-authoring benchmark cases for version 3.
